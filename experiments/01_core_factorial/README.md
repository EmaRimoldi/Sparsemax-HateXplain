# 01 - Core factorial

The confirmatory experiment crosses target geometry, loss geometry, and semantic
content. All eight conditions supervise raw `[CLS]` attention scores in the same
six final-layer heads and use paired seeds.

The human-versus-random contrast is the selectivity test: random masks have the
same positive-token count as the human mask, are sampled outside it when possible,
and are deterministic from the post ID and random-rationale seed.
